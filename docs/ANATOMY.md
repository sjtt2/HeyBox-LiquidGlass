# 底部导航栏结构解剖（沟通基准文档）

> 本文是后续所有讨论的术语基准。请以编号（A/B/C/D/E/F/G）指代对应元素。

## 整体结构图

```
屏幕底部（从上往下看）

        ┌─────────────────────────────────────────────────┐
        │              A. 玻璃长条本体                      │ ← 整条玻璃的"底"
        │   （折射+模糊+tint染色+内阴影 都画在这一层）        │    决定它是白磨砂
        │                                                 │    还是深色/发黑
        │   ┌───────┐ ┌───────┐   ┌────┐   ┌───────┐      │
        │   │ C     │ │ C     │   │ D  │   │ C     │ │C│  │
        │   │ 图标+字│ │图标+字 │   │ ➕ │   │图标+字 │ │ │  │
        │   └───────┘ └───────┘   └────┘   └───────┘ └─┘  │
        │                                                 │
        │      [B. 液泡：套在当前选中 C 下面的玻璃小胶囊]       │ ← 只罩住一个tab
        └─────────────────────────────────────────────────┘
         ██████████████████ 系统手势条区域 ██████████████████
```

## 元素清单

| 编号 | 标准名称 | 技术身份 | 颜色由谁决定 |
|---|---|---|---|
| **A** | 玻璃长条本体 | LiquidGlassTabBar 自身的玻璃渲染层（AGSL 折射+模糊+tint 染色+内阴影） | `currentTintColor()` / `adaptiveTintColor`（我们 Hook 过的就是它） |
| **B** | 液泡 | `droplet`——内嵌的小号 LiquidGlassView，套在选中 tab 下面 | TabBar 的 `onAppearanceChanged` → `droplet.overLight` |
| **C** | 标签文字+图标（×4） | tabsRow 里的 TextView / ImageView | `overLightAppearance` → `updateTabStyles()`（黑白切换） |
| **D** | 发布按钮 | 原 App 的 `vg_mid_tab`（加号胶囊） | 原 App 固定样式 |
| **E** | 红点提示 | 原 App 的 `vg_tips` | 原 App |
| F | 内容容器 | `fl_container`（玻璃背后被折射的页面内容） | 原 App |
| G | 宿主容器 | 我们创建的无缝 FrameLayout，只负责承载 A-E | 无自身颜色 |

## 三个可独立控制的"外观开关"

| 开关 | 影响范围 | 当前状态(v3.0.0) |
|---|---|---|
| **A 的底色** | 只有 A | 跟随应用主题：亮=白磨砂 / 暗=微白（❌ 你说这版暗色也不对了） |
| **C 黑白切换** | 只有 C | ❌ 本版失效（之前随背景亮度自动切黑白的那版是好的） |
| **B 外观** | 只有 B | 本版固定不变了（之前会随背景变色） |

## 历史版本行为对照

| 版本 | A 玻璃长条 | C 标签文字图标 | 你的评价 |
|---|---|---|---|
| **v2.5.0** | 随背景反色：暗内容上→偏白玻璃；亮内容上→偏黑玻璃 | 随背景亮度切黑白 | 「暗色模式下效果非常好」但亮色割裂 |
| v2.8.0 | 亮主题→白；暗主题→微白（理论） | 随背景 | 「只有液泡变了」 |
| **v3.0.0（当前）** | 恒定跟随主题：亮=白磨砂 / 暗=微白 | ❌ 失效 | 「两种模式都没黑底了，自适应也没了」 |
